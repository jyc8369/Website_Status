## English

### Status page

This public page shows the current status of services behind [status.jyc8369.dev](https://status.jyc8369.dev).

It reports availability for Proxy server 1, Device B, and Device C. When a device responds with a valid report, the page also shows CPU usage and uptime. Status checks refresh automatically every 30 seconds; use **Refresh** to check immediately.

Open [status.jyc8369.dev](https://status.jyc8369.dev) to view the page. The [GitHub Releases page](https://github.com/jyc8369/Website_Status/releases) is the place to check for downloads; no downloadable release has been confirmed.
